# Temporary preview imagery

All six images below were generated with OpenAI image generation for this design preview. They are fictional illustrations, not photographs of Vic’s real artwork or a portrait of Vic. The site visibly labels preview content and production approval requires the artist’s original photographs in Sanity. Do not present these as the artist’s work.

The supplied visual mockup guided composition, palette and typography. It is not served as a website image. Original generated PNGs are kept only in ignored local `output/imagegen/`; `public/images/demo/` contains the optimized WebP delivery assets. `scripts/prepare-images.mjs` encodes fixed responsive widths using Sharp; it does not creatively edit the images. Wave motifs are code-native SVG.
